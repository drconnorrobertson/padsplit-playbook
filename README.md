# PadSplit Playbook

Independent educational website by Dr. Connor Robertson about the PadSplit and workforce co-living operating model.

## Local development

```bash
npm install
npm run dev
```

Production domain: `padsplitplaybookbook.com`

The nine retired utility variants redirect permanently to `/insights/utilities-field-guide`; their old core articles were identical. Keep redirect sources out of the canonical guide registry and sitemap. `node scripts/check-utility-consolidation.mjs` checks the route map, current inventory, related links and the retained guide's fictional arithmetic.
